## Deskripsi Repository
Repository ini berisi penyelesaian tugas Pemrograman Dasar TLS 2026 yang terdiri dari dua fase:
1. Fase 1: Dokumentasi perancangan logika berupa Flowchart (Problem 1) dan Pseudocode (Problem 2) beserta penjelasan logika terperinci dalam file PDF.
2. Fase 2: Implementasi program C++ menggunakan library `<iostream>` serta penulisan fungsi mandiri (*User-Defined Functions*) untuk memecahkan Problem 1 (`problem1.cpp`) dan Problem 2 (`problem2.cpp`).
